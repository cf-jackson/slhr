# HR 月結考勤檢核系統
https://cf-jackson.github.io/slhr/
這是一個可直接用瀏覽器開啟的 HR 考勤月結檢核網頁工具。

目前可使用網址：[https://cf-jackson.github.io/slhr/](https://cf-jackson.github.io/slhr/)。若後續專案移轉組織、改名或調整部署位置，請同步更新此連結。

## 主要功能

- 匯入 Excel / CSV 考勤資料
- 依月份與人員整理月結考勤
- 自動補齊 1 號到月底每日資料
- 標示未上班 / 休假日
- 午休不刷卡，依班別扣午休（A、B、P 扣 60 分鐘，C 扣 70 分鐘）；每日工時低於該班別應上班時數時以紅字提醒（P 班兼職不判定）
- 月加班超過上限（預設 54 小時，可在基本設定調整）後以紅字提醒
- 加班依倍數表計算「加班倍數後時數」並於每位員工下方合計（工作日與週六前 2 小時 ×1.34、第 3 小時起 ×1.67；週日與國定假日有出勤，8 小時內直接計 8 小時，第 9～10 小時 ×1.34、第 11 小時起 ×1.67；平日颱風假不計考勤、不計加班，遇週六、週日則依週六、週日規則）
- 週六、週日與國定假日出勤，A／B／C 班工時一律依 08:00～12:00、12:30～16:30 計算（08:00 前到不計，跨 12:00～12:30 扣 30 分鐘）
- 只有上班或只有下班打卡的日子標示異常，不推算工時
- 可匯入人員班別對應表（員工編號、姓名、班別），資料只存在瀏覽器
- 匯出帶有顏色提醒的 Excel 檢核表

## 使用方式

1. 用瀏覽器開啟 `index.html`
2. 點選 `匯入 Excel`
3. 選擇考勤資料檔案
4. 檢查月份、人員與每日明細
5. 點選 `匯出檢核 Excel`

## Excel 欄位

建議 Excel 第一列包含以下欄位：

| 欄位 | 說明 |
|---|---|
| 員工序號 | 員工識別 |
| 考勤號碼 | 考勤系統編號 |
| 姓名 | 員工姓名 |
| 日期 | 考勤日期 |
| 上班1 | 第一段上班時間 |
| 下班1 | 第一段下班時間 |
| 上班2 | 第二段上班時間 |
| 下班2 | 第二段下班時間 |
| 合計 | 每日總工時 |
| 加班時數 | 每日加班時數 |
